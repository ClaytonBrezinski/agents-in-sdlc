Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con situaciones realistas, una aplicación completa y un trabajo pendiente compartido. Planificarás cambios, escribirás código, probarás el comportamiento, revisarás solicitudes de incorporación de cambios y gestionarás el trabajo con agentes mediante un proceso iterativo.

## Escenario

Eres una nueva persona desarrolladora de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo de software. El trabajo pendiente del equipo ya está registrado como incidencias de GitHub para que puedas elegir una. Incluye nuevas funciones, como filtros y paginación, y mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza la situación compartida de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, las instrucciones, las aptitudes, los agentes personalizados, Playwright MCP, Agent Merge y comandos de barra prácticos.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub en la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo Agente de Copilot Chat, los servidores MCP y los agentes personalizados sin salir del editor.
